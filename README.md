# MatOppskrifter – ribbe-reimagined

Dokumenterer kreative måter å bruke restemat fra ferdigstekt ribbe. Hver oppskrift har ingredienser, fremgangsmåte og tips for å gjøre kjøkkenjobben mest mulig praktisk, og er beregnet på ca. 4 porsjoner.

## Innhold

- `ribbe-reimagined/sticky-ribbe-terninger.md`
- `ribbe-reimagined/pulled-ribbe-sticky.md`
- `ribbe-reimagined/sitrus-yoghurt-dessert.md`
- `ribbe-reimagined/sprø-kålsalat.md`
- `ribbe-reimagined/julepølse-og-medister.md`

Beskrivelsen i hver fil følger samme README-vennlige struktur for lett gjenbruk og deling.
